# AdventureWorks Frontend

This is the Vue 3 frontend for the AdventureWorks Workshop project.

## Workshop TODOs

- Implement service methods in `src/services/peopleService.js` and `src/services/productsService.js` to call the .NET API (see TODOs in those files).
- Complete table rendering and data loading logic in `src/views/PeopleView.vue` and `src/views/ProductsView.vue` (see TODOs and placeholder comments).
- Add search functionality and connect UI to backend endpoints.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Access the app at [http://localhost:3000](http://localhost:3000)

## Key Files

- `src/services/peopleService.js`: Service for People API calls (contains TODOs).
- `src/services/productsService.js`: Service for Products API calls (contains TODOs).
- `src/views/PeopleView.vue`: People page UI and logic (contains TODOs).
- `src/views/ProductsView.vue`: Products page UI and logic (contains TODOs).
